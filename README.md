# Groovy + Jenkins Shared Libraries

Laboratorio práctico para aprender **Groovy desde cero** y aplicar lo aprendido en **Jenkins Shared Libraries**.

## Ruta
1. Groovy desde cero.
2. Collections y closures.
3. Métodos, POO y errores.
4. Groovy aplicado a Jenkins.
5. Shared Libraries.
6. Labs integradores.

## Estructura
- `01-groovy-basics/`
- `02-collections-closures/`
- `03-functions-oop-errors/`
- `04-groovy-jenkins/`
- `05-shared-library/`
- `06-labs/`
- `docs/`
- `solutions/`

## Requisitos
JDK 17+, Groovy, VS Code, Git y Jenkins para los labs de integración.

Consulta [docs/01-vscode-setup.md](docs/01-vscode-setup.md).

> Primero aprendemos a programar en Groovy. Después usamos Groovy para construir código reutilizable en Jenkins.
